# Promotion Contract

Promotion is the only approved bridge from research to live.

## Required live branch behavior

- Validate promotion candidate manifests before loading.
- Load accepted artifacts in shadow mode only during Stage 11.
- Reject the same artifact as a live order input.
- Display shadow diagnostics without live controls.

## Review evidence

Promotion review must include dataset, feature, strategy, validation split, side, regime, slippage, funding, missingness, drift, and skip-reason evidence.

## Non-goal

Stage 2 does not authorize paper or live trading from research artifacts.
